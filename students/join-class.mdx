Joining a class connects you to your teacher's assignments, announcements, and resources. Your teacher will give you a class code, such as MATH7X42, which you enter to join. This page walks you through the process step by step.

<Steps>
  <Step title="Click Join Class">
    On your dashboard or in the navigation menu, locate and click the **Join Class** button.
  </Step>
  <Step title="Enter the teacher code">
    Type the code your teacher provided into the input field. Codes look like MATH7X42, with letters and numbers.
  </Step>
  <Step title="Verify the class details">
    Before joining, confirm that the displayed class name and teacher name match what you expect. This prevents joining the wrong class by mistake.
  </Step>
  <Step title="Confirm to join">
    Click the **Join** button to enroll. You will immediately see the class appear on your dashboard.
  </Step>
</Steps>

### What happens next

Once you join, the class card appears on your dashboard. You can now view assignments, participate in activities, and track your progress for that class.

<Note>
  You cannot join the same class twice. If you try to re-enter a code for a class you already belong to, you will see a message that you are already enrolled.
</Note>

## Invalid or expired codes

If you see an error that the code is invalid or was regenerated:

- Ask your teacher for the current, active class code
- Double-check that you typed the code correctly
- Make sure you are not confusing a similar character (like 0 and O)

<Tip>
  If your teacher regenerated the class code, the old code will no longer work even if you previously saw it. Always ask for the latest code if you are unsure.
</Tip>
